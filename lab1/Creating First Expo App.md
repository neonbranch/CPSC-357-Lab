# Creating Your First Expo App

This guide walks you through creating and running your first Expo React Native application.

**Prerequisites:** Complete the Environment Setup Guide first.

---

## Step 1: Create a New Expo App
```
npx create-expo-app@latest my-expo-app --template blank
cd my-expo-app
```

---

## Step 2: Run the Expo App
```
npx expo start
```

---

## Step 3: Run App on Device

Choose one:
- Phone: Open Expo Go app and scan QR code
- Android Emulator: Press `a`
- iOS Simulator (macOS only): Press `i`

---

## Step 4: Test Hot Reload
Edit App.js and save changes to see live reload.

---

## Step 5: Stop the App
Press Ctrl + C
