# Assets Folder

This folder should contain the following image files for the app:

- `icon.png` - App icon (1024x1024px recommended)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `splash-icon.png` - Splash screen icon
- `favicon.png` - Web favicon (48x48px)

You can generate these using Expo's asset generation tools or create them manually.

For now, you can use placeholder images or copy assets from previous lab projects.
